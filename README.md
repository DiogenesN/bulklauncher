# bulklauncher
A simple apps launcher. You can launch multimple apps simultaneously with one click. You can select which apps you want to be launched this time. You can add and remove apps from the list. You can set it to Launch automatically once you starts the bulklauncher app.

# Installation/Usage
  1. Install the following libs:

         yad
         sed
         gawk
         grep
         bash
         coreutils

  2. Open a terminal and run:

		  chmod +x ./bulklauncher
		
  3. Copy the script to /usr/local/bin:
  
		  sudo cp ./bulklauncher /usr/local/bin/

  4. Launch the app:

          bulklauncher

# NOTE:
For proper operation, copy the bulklauncher script to /usr/local/bin.
